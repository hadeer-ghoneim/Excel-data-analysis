# 📊 Excel Data Analysis – NYSE Financial Project

## 📌 Project Overview

A complete financial analysis project using real-life data from the **New York Stock Exchange (NYSE)**. The project covers the full data analysis pipeline: cleaning, analysis, visualization, dashboarding, and financial forecasting.

---

## 🎯 What I Built

### 1️⃣ Data Analysis & Visualization
- Performed **descriptive statistics** (mean, median, range, standard deviation)
- Compared **Information Technology** vs **Industrials** sectors (Year 4)
- Created **histograms** to identify distribution shapes (right‑skewed)
- Used **pivot tables** and spreadsheet formulas for aggregations

### 2️⃣ Dynamic P&L Dashboard
- Built an interactive **Profit & Loss Statement** dashboard
- Dynamic filtering by company / sector / year
- Visualized key metrics: Revenue, COGS, Gross Profit, Operating Margin

### 3️⃣ Financial Forecasting Model
- Developed a **3‑scenario forecasting model**:
  - 📈 **Strong Case**
  - 📊 **Base Case**
  - 📉 **Weak Case**
- Forecasted **Year 5 & Year 6** financials using historical trends
- Sensitivity analysis on: Revenue growth, Gross Margin, Operating Margin

## 📈 Key Insight from Analysis

> *"Industrials sector sells more goods than Information Technology in Year 4, but IT has higher variability in Cost of Goods Sold."*

| Sector | Median COGS | Mean COGS | Range | Std Dev |
|--------|-------------|-----------|-------|---------|
| IT | \$2.21B | \$8.18B | \$131.18B | \$19.32B |
| Industrials | \$5.75B | \$10.24B | \$80.10B | \$12.99B |

- Both distributions are **right‑skewed** (mean > median)
